# Flytrex

> Flytrex is an autonomous drone delivery operator headquartered in Tel Aviv, Israel,
> with US operations centered on the Dallas-Fort Worth metroplex and North Carolina.
> It flies food and small goods from partner restaurants and retailers to consumer
> backyards in roughly five minutes using its own Sky-series aircraft, ground docks
> and a remote-operations control center.

## Agent-relevant status

- **Public API: none.** Flytrex publishes no developer program, API reference, or
  machine-readable specification (no OpenAPI, AsyncAPI, GraphQL SDL, or Postman
  collection) at any location probed on 2026-08-16.
- **MCP server: none.** No hosted or stdio Model Context Protocol server is published.
- **A2A agent card: none.** `/.well-known/agent-card.json` and `/.well-known/agent.json`
  return 404 on every Flytrex-controlled host.
- **Retired developer program.** A public OAuth2 "Flytrex Live API" for consumer-drone
  telemetry once ran at `x.flytrex.com`; that host no longer resolves in DNS. See
  `lifecycle/flytrex-lifecycle.yml`.
- **Merchant integration is not self-service.** The merchant surface is a sign-in-only
  portal at partners.flytrex.com; onboarding runs through Flytrex's merchants form,
  not through a published API.
